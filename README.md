## Arrancar

**Importante:** no abras `index.html` con doble clic (pantalla en blanco). Hay que usar el servidor.

### Opción fácil (Windows)

Doble clic en **`start.bat`** — instala dependencias si hace falta, levanta Vite y abre el navegador.

### Manual

```powershell
cd C:\Users\Eduardo\my-agentes
npm.cmd install
npm.cmd run dev
```

Abre **http://localhost:5173**

> En PowerShell usa `npm.cmd` (no solo `npm`) si ves error de *Execution Policy*.
